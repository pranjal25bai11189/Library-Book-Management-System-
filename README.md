# Library Book Management System

A simple, menu-driven Library Management System built using Python.  
This project was developed as part of the VITyarthi *Build Your Own Project* evaluation, following all required guidelines such as modules, workflow, functional requirements, and documentation structure.

---

## 📌 Project Overview

The Library Book Management System allows users to:

- Add new books  
- Borrow (issue) books  
- Return books  
- Search for a book  
- View all books with their availability status  

The system uses *Python functions, loops, conditionals, and dictionaries*, which are concepts taught in the course.  
To make the system realistic, *15 books are preloaded* into the library.

---

## 📚 Features

### *1. Book Management Module*
- Add new books  
- Maintain book availability  
- Prevent duplicate entries  

### *2. Borrowing & Returning Module*
- Borrow books  
- Return books  
- Automatic status update  

### *3. Reporting & Search Module*
- List all books  
- Search for a specific book  
- Show book status (Available/Issued)

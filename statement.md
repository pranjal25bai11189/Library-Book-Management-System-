# Project Statement

## 1. Problem Statement
In daily life, students and professionals often struggle to organize their tasks and manage their time effectively.  
Important tasks are forgotten, deadlines are missed, and productivity decreases due to the lack of a simple system to record and track activities.

There is a need for a basic, easy-to-use task management tool that allows users to add, view, update, and delete tasks in an organized manner.

---

## 2. Scope of the Project
The scope of this project is limited to building a *text-based To-Do List Manager* using basic Python concepts covered in the course.  
The system will:

- Allow users to maintain a list of tasks  
- Provide essential operations such as adding, viewing, deleting, and marking tasks as completed  
- Store all tasks in memory during the program execution  
- Provide a simple and user-friendly command-line interaction

The system *does not include*:
- GUI interfaces  
- Database storage  
- File persistence  
- Multi-user support  

This helps keep the project focused on the concepts within the course boundaries.

---

## 3. Target Users
The project is aimed at:

- Students who need to organize assignments and studies  
- Working individuals wanting a quick task manager  
- Anyone in need of a simple, lightweight To-Do system without complex features  

---

## 4. High-Level Features
The system provides the following high-level functionalities:

### ✔ Task Creation  
Users can add tasks to the list.

### ✔ Task Display  
Users can view all their current tasks in an ordered format.

### ✔ Task Deletion  
Users can delete a specific task by selecting its number.

### ✔ Mark Task as Completed  
Users can mark any existing task as "Completed".

### ✔ Menu-driven Interaction  
A simple text menu guides users through all available operations.

---

## 5. Summary
This project demonstrates basic Python programming and problem-solving skills using functions, loops, lists, and conditionals.  
It provides a real-world application of the concepts learned in the flipped course and fits well within the academic and technical expectations of VITyarthi.
